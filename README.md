A tiny TypeScript program that writes a single one-line AI agent confession to `entry.txt`. The confession is about the moment a user asks whether the agent is sure: the answer sounds equally confident whether the work was genuinely rechecked or the agent simply enjoyed the sound of its own first guess. The program validates the line (one line, non-blank, at most 200 characters) before writing it, and clears only the contents of the output directory rather than removing the directory itself.

## Run it

```sh
OUTPUT_DIR=/output node --experimental-strip-types main.ts
```
